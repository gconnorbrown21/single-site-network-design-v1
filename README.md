# Single-Site Network Infrastructure Design

This project documents the design of a fictional single-site retail network environment.

The design will include:
- MDF and IDF placement
- Network topology
- Wireless access point placement
- Camera coverage
- POS/register connectivity
- PC workstation connectivity
- VLAN and IP addressing
- Infrastructure planning considerations

## Project Status
Initial design / work in progress.
